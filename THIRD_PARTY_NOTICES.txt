B. IN THE RELEASE BINARIES (NOT in git)
---------------------------------------
The Release assets of this repository include prebuilt libraries (.a / .dll)
that the vendor:* modules link against. They are built from the upstream
projects above, and also include:

  SQLite (libsqlite3)        public domain
  miniaudio (libminiaudio)   public domain or MIT-0
  OpenSSL 3 (libssl, libcrypto)  Apache-2.0
  GNU libiconv, libintl      LGPL-2.1-or-later   (dynamic libraries; replace them freely)
  MariaDB Connector/C        LGPL-2.1            (libmariadb.dll; replace it freely)
  libwinpthread              MIT / ZPL

The LGPL libraries are shipped as separate DLLs and can be replaced by the user.
The license text of each one is inside the Release archive.
