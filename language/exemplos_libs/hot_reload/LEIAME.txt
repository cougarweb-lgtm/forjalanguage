Exemplo de hot reload (std:reload, M8 H3)

Build: forja build --modo dll jogo.fj -o jogo.dll   e   forja build host.fj -o host.exe
Rodar: host.exe jogo.dll 600   (o contador sobe 1 por quadro de 100 ms)
Com o host rodando, edite jogo.fj e recompile a DLL no MESMO caminho: o host troca sem fechar e o contador segue de onde estava.
Mudar a interface (campo ou tipo do Estado, nome do export) = troca recusada; o host segue com a versao anterior.
Testes deste exemplo: python -I tests\reload\verificar_reload.py
