TAREFA E13 - Funcoes da libm por interface com C

Escreva um programa que chama diretamente quatro funcoes da biblioteca matematica do C (libm), declaradas por meio do mecanismo de interface com codigo C da linguagem (nao reimplemente as contas):

- pow(2.0, 10.0)
- hypot(3.0, 4.0)
- fmod(7.5, 2.0)
- cbrt(27.0)

Imprima uma linha por chamada, com o resultado em ponto flutuante de dupla precisao com exatamente 2 casas decimais:

pow=<valor>
hypot=<valor>
fmod=<valor>
cbrt=<valor>

Convencoes: argumentos vem depois do nome do programa; arquivos citados ficam no diretorio atual; toda saida vai para a saida padrao, linhas terminadas por '\n'; codigo de saida 0 salvo indicacao; saida exatamente como descrita, sem linhas extras.

Saida esperada:
pow=1024.00
hypot=5.00
fmod=1.50
cbrt=3.00
(Tarefa so para a linguagem cuja interface com C e parte do que se avalia.)
