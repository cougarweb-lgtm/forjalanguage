TAREFA E06 - Contar linhas com erro tratado

Escreva um programa que recebe como unico argumento o nome de um arquivo e imprime quantas linhas ele tem.

- Cada '\n' encerra uma linha; se o arquivo nao esta vazio e o ultimo byte nao e '\n', o texto final tambem conta como uma linha. Arquivo vazio: 0 linhas.
- Imprima somente o numero, em uma linha (codigo de saida 0).
- Se o arquivo nao existe: imprima `erro: arquivo nao encontrado: <nome>` (com o nome exatamente como foi dado) e saia com codigo 2.
- Se nenhum argumento for dado: imprima `erro: informe o arquivo` e saia com codigo 2.

Convencoes: argumentos vem depois do nome do programa; arquivos citados ficam no diretorio atual; toda saida (inclusive as mensagens de erro acima) vai para a saida padrao, linhas terminadas por '\n'; saida exatamente como descrita, sem linhas extras.

O diretorio atual tem os arquivos dados.txt, sem_fim.txt e vazio.txt para teste.
