CARTAO FORJA - forja 0.19.0 (Linguagem v1.11). Fonte unica por TEMA; o historico fica no GUIA-08.
Blocos ```fj compilam como estao (arquivo raiz precisa de proc main). Marca depois de fj: Exxxx = 1o erro do check; Rxxxx = erro de execucao; exit=N = codigo de saida.

== formato ==
Corpo de if/for/while/switch/proc/test em linhas separadas depois de `{`; chaves sempre; sem `;`; sem parenteses em if/while/for. Nomes ASCII (acento so dentro de aspas): tipos e unidades PascalCase, constantes MAIUSCULO, resto snake_case (E0102). Comentario so `//`. Inteiros 0xFF e 0b1010 (sem `_`). Logica `and or not`; `true false none`. Reservadas: const let var proc struct enum union unit pub export import as foreign test if else for in while switch case default break continue return defer try or_else and or not. Nao existem: `&& || ! ; ++ ?: nil range string fn def := /* */`.

== declarar ==
```fj
const MAX: i32 = 9
unit Metros: f32
proc main() {
    let a = 1
    var n: i32 = 0
    let g = 9.8
    let d: Metros = 2.0
    n += 1
    print(MAX + n + (a as i32) + (g as i32) + (d as i32))
}
```
`let` imutavel, `var` mutavel (so `var` aceita atribuicao: E0705), `const` pede tipo. Inteiro puro = `int` (64 bits); real puro = `f32`. `var` nunca alterada = E0707; local nunca lida = E0708 (prefixo `_` isenta); valor de proc descartado = E0709: escreva `_ = f()`. Tipos: i8 i16 i32 i64 u8 u16 u32 u64 int uint f32 f64 bool str cstr rawptr. Sem conversao implicita: `int + i32` = E0301, converta com `as`; bits crus `transmute(x, para = T)`; `& | ~ << >>` so em sem sinal. Unidade (`unit Metros: f32`) some no C: `+ - ==` na mesma unidade, trocar so com `as`. Faixa `vida: i32 in 0..=100 = 100`. Atribuicao so `=`, `+=`, `-=` (nao ha `*=` `/=`). Layout: `size_of(T) align_of(T) offset_of(T.campo)` e `static_assert(cond, msg = "txt")`.

== proc ==
```fj
struct Grifo {
    vida: i32 in 0..=100 = 100
    nome: str = "g"
}
proc mover(g: ^Grifo, dt: int, correr: bool = false) -> int {
    g.vida -= 1
    return dt
}
proc par(n: int) -> (q: int, r: int) {
    return n / 2, n - n / 2 * 2
}
proc main() {
    var g = Grifo{vida = 50}
    print(mover(&g, dt = 2))
    let q, _ = par(7)
    print(q)
}
```
1o argumento posicional, o resto `nome = valor` (2o posicional = E0502); os com padrao podem faltar. Parametro e imutavel (para alterar, `^T`: `&x`, `p^`, `p.campo`). Sem sobrecarga nem metodo. Struct: campo por linha, literal `Tipo{campo = valor}`. Retorno multiplo 2..8 nomeado; `let a, b = f()`, `_` descarta. Embutidos: `len min(a, b = c) max clamp(x, lo = a, hi = b) abs sqrt`. `pub export proc` gera simbolo C.

Armadilha (2o argumento posicional):
```fj E0502
proc soma(a: int, b: int) -> int {
    return a + b
}
proc main() {
    print(soma(1, 2))
}
```

== fluxo ==
`if a { } else if b { } else { }`, `for i in 0..<n`, `for i in 1..=n`, `while c`, `break`, `continue`, `defer f(x)` (fim do bloco, ordem inversa). `switch x { case A: ... }` cobre todos os casos ou tem `default` (E0607); enum sempre qualificado `Cor.verde`. `union Forma { Circulo, i32 }`: `let f: Forma = 9 as i32`, le por `switch c in f { case Circulo: ... }`.

== erro ==
```fj
enum Erro { nao_achou }
proc achar(id: i32) -> i32 ! Erro {
    if id == 0 {
        return Erro.nao_achou
    }
    return id * 10
}
proc dobro(id: i32) -> i32 ! Erro {
    let v = try achar(id)
    return v * 2
}
proc main() {
    print(achar(0) or_else -1)
    switch r in dobro(4) {
    case i32:
        print(r)
    case Erro:
        print("nao achou")
    }
}
```
`T ! E` valor ou erro; `! E` so erro. `try` repassa (o proc tem de devolver `! E` do MESMO E); `or_else` da o padrao; `switch r in f()` trata os dois. Ignorar o resultado nao compila (E0601). `T ! E` com lista dentro = E0311: devolva tupla `(data: [dynamic]u8, error: ?E)`. Opcional `?T`: `none` ou valor, le por `switch` ou `x or_else 0`, `x == none`. `assert(cond, msg = "texto")` (msg cstr) vale em qualquer lugar, tambem em release, e falso e R0003 com exit 101 (`panic("texto")` idem); `expect(cond)` so dentro de `test` (E0801). Saida do processo: `main` nao devolve valor; `proc main() -> ! E` que devolve erro sai 1 (R0004); codigo qualquer: `os.exit(n)` (ver saida).

```fj R0003
proc main() {
    assert(1 == 2, msg = "falhou")
}
```

== memoria ==
```fj
import "std:mem"
struct Bala {
    dano: int = 1
}
proc main() {
    let b = new(Bala, em = heap)
    defer delete(b)
    var l = make([dynamic]int, em = heap, cap = 4)
    defer delete(l)
    append(&l, item = 7)
    let t = new(Bala, em = escopo)
    let a = mem.arena_create()
    defer mem.arena_destroy(a)
    let c = new(Bala, em = a)
    print(b.dano + t.dano + c.dano + l[0])
    frame_reset()
}
```
Toda alocacao diz `em = heap | frame | escopo | <Arena> | <Pool>`. `heap`: dono unico, precisa de `delete`/`defer delete` ou entrega (E0317); vazamento visto no fim do `run` em dev = R0009. `frame`: 16 MiB, `frame_reset()` por quadro. `escopo`: solta no fim do bloco, so em `let`/`var`, nao sai dele (E0316). Arena/Pool de `std:mem`. Lista/map/soa sao DONOS e nao se copiam (E0311): `&l` altera, `l[..]` empresta. Guardar o resultado de `new`/`make` (E0310). `append(&l, ...)` recebe o ENDERECO. Alocacao impossivel = R0007; memoria mal usada (delete duplo por ponteiro guardado em estrutura ou liberado em outro proc, frame velho) = R0008, so dev. `delete(p)` 2x pelo MESMO nome nao acusa: zera `p` e o 2º delete e no-op.

```fj E0317
proc main() {
    let b = new(int, em = heap)
    print(b^)
}
```

== colecoes ==
```fj
proc main() {
    var a: [3]int = {1, 2, 3}
    var f: [dynamic, 2]int = {}
    var m = make(map[str]int, em = heap)
    defer delete(m)
    insert(&m, key = "x", value = 5)
    append(&f, item = a[1])
    var s: bit_set[Cor] = {Cor.azul}
    insert(&s, key = Cor.verde)
    print(get(m, key = "x") or_else 0)
    print(len(a[1..<3]) + len(f) + len(s))
    for i, x in a {
        print(i + x)
    }
}
enum Cor { verde, azul }
```
`[N]T` e valor (N exato, `{}` = zero); fatia `[]T` e visao (`a[..]`, `a[lo..<hi]`; array nao vira fatia sozinho); `for x in a`, `for &x in a`, `for i, x in a`; indice fora = R0006. `[dynamic, N]T`: lista de capacidade fixa, e valor; cheia = R0007. `map[K]V` (chave inteiro/enum/bool/str; `get` devolve `?V`; `m[k]` nao existe; nao mude o map dentro do `for` sobre ele, E0318). `has(s, key = c)`, `get_ptr`, `remove` tambem. `bit_set[Enum]` ate 64 membros. `soa[N]S` (`a.campo` e a coluna) e `matrix[R, C]T` (2..4, `m * v`, `transpose(m)`); `[N]T` numerico faz conta por elemento (`a + b`, `2 * a`) e `v.xy` le componentes; `quat{w = 1.0}` com `q * r` e `conj(q)`. `str` nao e indexavel por byte.

```fj
struct P {
    a: i32 = 0
    b: i64 = 0
}
static_assert(size_of(P) == 16, msg = "layout")
proc main() {
    let v: [3]f32 = {1.0, 2.0, 3.0}
    let w = v + v
    let p: [2]f32 = w.zy
    let q = quat{w = 1.0}
    print(f"{p[0]} {conj(q * q).w} {offset_of(P.b)}")
}
```

== texto ==
```fj
proc main() {
    let s = format(f"vida {7} x={3:03}", em = heap)
    defer delete(s)
    print(s)
    print(len(s))
    print(s == "vida 7 x=003")
}
```
`str` = bytes UTF-8 imutaveis (`len` em bytes, `==`; sem `+`, sem indice). `"..."` nunca interpola; so `f"{expr:[0][larg][.prec][x]}"` (`{{ }}`), 1o argumento de `print`, `format`, `format_c`. `print` aceita inteiro, bool, str, cstr; real so dentro de `f"..."` ou com `as int`. `format(..., em = heap)` -> `str`, `format_c` -> `cstr`; ambos pedem `delete`. `cstr` (`char*` terminado em NUL) existe so para falar com C: literal serve nos dois; `c as str` empresta sem copiar; `str` -> `cstr` so por `format_c(f"{s}", em = heap)`. `assert(msg = ...)` pede cstr (str = E0301).

== foreign ==
```fj
foreign {
    link "m"
    proc pow(x: f64, y: f64) -> f64
    proc c_remove = "remove"(caminho: cstr) -> i32
}
proc main() {
    print(pow(2.0, y = 3.0) as int)
}
```
Um item por linha; o nome do proc e o simbolo C (alias `proc nome = "simbolo"(...)` quando colide com palavra da Forja ou com `sqrt min max clamp abs`). Chamada: 1o posicional, resto nomeado, tambem em C. Atravessam: inteiros, reais, bool, `^T`, `?^T`, `cstr`, `?cstr`, `rawptr`, struct por valor, enum, callback `proc(a: rawptr) -> i32` (passe o NOME de um proc), `opaque Janela` (so `^Janela`). Nao atravessam: `str`, listas, map, soa, matrix. `cstr`/`^T` devolvido por C e emprestado (`delete` = E0310; nulo = R0005, use `?cstr`/`?^T`). Vetor C: `slice_from(p, len = n)`. Lib C pronta antes de escrever na Forja; header grande: `forja ligar x.h --link lib -o x.fj`. Nao reinvente a std: `exit`/`getenv` por msvcrt = `std:os`, `fopen` = `std:arquivo`, `strlen` = `len(c as str)`.

== modulos ==
`import "mods/geo"` (relativo a pasta do arquivo raiz, sem `.fj`), `import "std:mem" as m`, `import "vendor:x/y"`, `import "engine:x"`. Uso sempre `geo.nome`; so `pub` aparece (E1003); `main` e `pub export` so na raiz (E1004); ciclo = E1002; import nunca usado = E1005; nome de topo unico no programa. Apelido padrao = ultimo segmento e nao pode ser palavra reservada: use `as`. std: `std:mem` (Arena, Pool), `std:os` (`args() -> []str`, `env(name) -> ?str`, `exit(code)`; texto emprestado, sem `delete`), `std:arquivo` (`read_all(path) -> (data, error: ?FileError)`, `write_all(path, data) -> ?FileError`).

== testes ==
```fj
test "dobro" {
    expect(2 * 2 == 4)
}
proc main() {
}
```
`test "titulo" { expect(cond) }` junto do codigo; `forja test arq.fj [--filtro texto] [--json]` roda so os testes (exit 1 se algum falha); `expect` falho nao derruba os outros; vazamento em teste = R0009.

== saida ==
```fj
import "std:os"
proc main() {
    let a = os.args()
    print(len(a))
    if len(a) > 5 {
        os.exit(2)
    }
}
```
`os.args()[0]` e o programa; `os.env("HOME")` devolve `?str`. `os.exit(code)` (0..255, outro = R0012) descarrega stdout e nao relata vazamento. Arquivo inteiro: `arquivo.read_all(path)` devolve `data` DONA (delete mesmo com erro) e `error: ?arquivo.FileError`; `write_all(path, data = d[..])` devolve `?FileError`. Desestruturar para `delete` pede `var`. Stderr: sem API na std (use foreign).

```fj exit=3
import "std:os"
proc main() {
    os.exit(3)
}
```

```fj
import "std:arquivo"
proc main() {
    var dados, erro = arquivo.read_all("nao_existe.bin")
    defer delete(dados)
    switch e in erro {
    case arquivo.FileError:
        print("falhou")
    case none:
        print(len(dados))
    }
}
```

== cli ==
`forja check [--max-erros N] [--stdin] a.fj` (silencio + exit 0 = ok; ate 20 erros por rodada, N 1..100) | `run [--release] a.fj [-- args]` | `build [--modo exe|dll|c] [--release] a.fj -o saida` | `test` | `ast [--tipos]` | `explicar CODIGO` | `ligar x.h --link lib` | `--versao`. Padrao: backend x64 em dev (sem gcc), c em `--release` e `--modo c`; `--backend c|x64` escolhe. Saida: 0 ok, 1 diagnostico, 2 uso/E-S, 3 interno, 101 falha de execucao. Diagnostico = 1 linha JSON no stdout (`codigo tipo arquivo linha coluna coluna_fim causa explicacao forma_certa`); erro de execucao = JSON no stderr. No PowerShell 5.1 chame o forja pelo Bash ou por `subprocess` do Python (ele estraga aspas e argumento vazio); `--args-file` ainda nao existe. Exemplo: `forja run a.fj -- um "dois tres"`.
