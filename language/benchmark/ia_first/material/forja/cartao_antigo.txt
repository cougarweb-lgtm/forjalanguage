CARTAO FORJA (antigo, regras/forja.md de 10/11/2026): escrever .fj sem errar

**Formato:** corpo de `if`/`for`/`while`/`proc`/`switch` em linhas separadas depois de `{`; sem `;`; sem parênteses em `if`/`while`/`for`. Nomes ASCII: tipos `PascalCase`, constantes `MAIUSCULO`, o resto `snake_case`.
**Declarar:** `let x = 1` (imutável) · `var n: i32 = 0` (mutável) · `const MAX: i32 = 9`. Só `var` aceita atribuição.
**Proc:** `proc nome(a: int, b: int = 0) -> int { return a }`; chamada `nome(1, b = 2)` (1º posicional, resto nomeado). `proc main()` é a entrada.
**Struct:** campos um por linha, `vida: i32 in 0..=100 = 100`; literal `Tipo{campo = valor}` (chaves, nomeado).
**Laços:** `for i in 0..<n`, `for i in 1..=n`, `while cond`, `break`, `continue`. Lógica `and or not`.
**Erro:** `proc f() -> i32 ! Erro` com `enum Erro { ... }`; `try f()`, `f() or_else -1`, `switch r in f() { case i32: ... case Erro: ... }`.
**Ponteiro:** `^T` nunca nulo, `?^T` anulável (`none`), `&x`, `p^`, `p.campo`; `n as ^T` checa nulo.
**Texto:** `str` (`len(s)` em bytes, `==`), `cstr` só para C (`assert(c, msg = c2)`).
**Converter:** só `as`; bits crus `transmute(x, para = T)`; `& | ~ << >>` só em sem sinal.
**Chamar C:** `foreign { link "m"  proc pow(x: f64, y: f64) -> f64 }` (`sqrt`, `min`, `max`, `clamp`, `abs` são embutidos desde a v1.11: nome reservado, não declare em `foreign`). **DLL:** `pub export proc`.
**REGRA — NÃO REINVENTAR A RODA (usuário, 08/11/2026):** antes de escrever em Forja qualquer capacidade (compressão, banco, rede, áudio, imagem, janela, matemática, parser…), procurar lib madura e gratuita e USAR por `foreign`: lib **C** (direto; testado com `libm`), **DLL do Windows** (`link "kernel32"`; testado com `GetTickCount64`), **C++** (por wrapper `extern "C"` + `foreign`). Forja pura só com o motivo escrito (não existe lib, licença não serve, precisa ser nativa/segura). Conferir licença/versão/atividade (Regra #8) e, para headers grandes, gerar as declarações com `forja ligar` em vez de escrever à mão. **APP NOVA = PESQUISA ANTES (usuário, 08/11/2026):** ao começar um app novo em Forja, o 1º passo é listar o que já existe para cada peça: lib C, DLL do Windows, lib C++ (wrapper) e também **programa `.exe` de linha de comando** (ex.: ffmpeg, 7z, pandoc, curl, tesseract, gcc). A Forja gerencia essas peças: chama a lib por `foreign` e o `.exe` por processo (testado: `foreign { link "msvcrt"  proc system(comando: cstr) -> i32 }` rodou `cmd /c echo` e devolveu o código de saída). Registrar no app, para cada peça escolhida: nome, versão, licença, origem/URL, caminho e como foi testada; o `.exe` externo é conferido (existe? código de saída 0?) e o erro vira mensagem IA-first, nunca é ignorado. A Forja fica na cola, na segurança e no jogo; a roda pronta fica com a lib ou o `.exe`. Limite atual: só tipos simples atravessam (inteiros, reais, ponteiros, `cstr`; sem `[dynamic]T`/`str`).
**print:** inteiro, bool, texto; real com `as int` (dentro de `f"..."` o f32 vale).
**Array/fatia:** `var a: [4]int = {1, 2, 3, 4}` (N exato), `a[i]`, `a[1..<3]`, `a[..]`, `len(a)`, `for x in a`, `for &x in a`, `for i, x in a`; array é valor (copia), fatia `[]T` é visão (array não vira fatia sozinho: `f(a[..])`); índice fora = R0006.
**Memória (v1.6):** toda alocação diz `em = heap|frame`. `let g = new(T, em = heap)` + `defer delete(g)`; `var l = make([dynamic]int, em = heap, cap = 8)`, `append(&l, item = x)` (endereço!), `delete(l)`, `frame_reset()` por quadro. Lista é dona e NÃO se copia (E0311): `&l` para alterar, `l[..]` para emprestar, `for &x in grade` em lista de listas. Resultado de `new`/`make` tem de ser guardado (E0310). Lista não atravessa DLL/`foreign`.
**Opcional `?T` (v1.7):** `let a: ?i32 = none` ou valor; ler só por `switch v in a { case i32: ... case none: ... }` ou `a or_else 0`; `a == none`; sem `try`, sem `??T`. `?cstr` = `char*` que pode ser NULL.
**Union (v1.7):** `union Forma { Circulo, i32 }`; `let f: Forma = Circulo{raio = 2}`; número pede `9 as i32`; ler por `switch c in f { case Circulo: ... }`; sem valor zero, sem `==`.
**Retorno múltiplo (v1.7):** `proc par(n: int) -> (a: int, b: int) { return n, n + 1 }`; `let a, b = par(1)`; `_` descarta (só em let múltiplo); tupla não vira variável nem tem `==`.
**Texto formatado (v1.7):** `print(f"vida {v} x={x:03}")`; `let s = format(f"...", em = heap)` (str) + `delete(s)`; `format_c(...)` → `cstr`; `{{ }}` = chave.
**Import (v1.8):** `import "mods/geo"` (relativo à pasta do arquivo raiz, sem `.fj`) ou `import "std:mem" as m`; uso sempre `geo.nome`; só `pub` aparece; `main`/`pub export` só na raiz; nome de topo único no programa.
**Escopo (v1.8):** `em = heap|frame|escopo|<Arena>|<Pool>`; `let g = new(T, em = escopo)` solta sozinho no fim do bloco e não sai dele (E0316); `new(T, em = heap)` local precisa de `delete`/entrega (E0317); em dev, vazamento = R0009.
**Foreign avançado (v1.8b):** `opaque Nome` dentro de `foreign` (só `^Nome`/`?^Nome`); `enum Modo { a = 0, b = 5 }` (valor explícito; na mesma linha pede vírgula); struct dentro de struct por valor; callback `comparar: proc(a: rawptr, b: rawptr) -> i32` em proc foreign (passe o nome de um proc da Forja; `?proc` e valor de proc fora de foreign = E0907); `cstr` devolvido por foreign é emprestado (`delete` = E0310); vetor C = `slice_from(p, len = n)` (`^T`/`?^T` de foreign, `n` inteiro → `[]T` emprestada; nunca `p as rawptr as ^[N]T`); `import "vendor:x/y"` e `import "engine:x"`; `forja ligar x.h --link lib -o x.fj` gera o `foreign` (também `--cpp` e `--dll`).
**Literais (v1.10):** `0xFF` e `0b1010` valem (sem `_`); literal de struct pode quebrar linha depois de `{` e de `,`; foreign com nome de palavra da Forja ou colidente usa alias: `proc c_remove = "remove"(caminho: cstr) -> i32`.
**Comentário:** `//` até o fim da linha; não há `/* */`.

**map (v1.9):** `var m = make(map[str]int, em = heap)` + `defer delete(m)`; `insert(&m, key = k, value = v)`, `get(m, key = k) or_else 0`, `has`, `remove(&m, ...)`, `get_ptr`; chave = inteiro/enum/bool/str; dono (cópia = E0311); `m[k]` não existe; não mude o map dentro do `for k, v in m` (E0318).
**bit_set (v1.9):** `var s: bit_set[Cor] = {Cor.verde}`; `insert(&s, key = Cor.azul)`, `has`, `len`, `|` `&` `-`; enum sem `= valor`, até 64 membros (E0319).
**soa (v1.9):** `var a: soa[N]S = {}` (zera tudo, ignora padrões) ou `make(soa[dynamic]S, em = heap)`; `a[i].campo`, `a.campo` = fatia da coluna; `&a[i]` e `for &item` = E0320.
**matrix (v1.9):** `matrix[2, 2]f32 = {1.0, 2.0, 3.0, 4.0}` (R, C literais 2..4; literal por linhas); `m[i, j]`, `m * m`, `m * v`, `transpose(m)`; `v * m` = E0321.
**Fora da v1.9:** `[Enum]T`, `.xyzw`, struct como chave de map; map/bit_set/soa/matrix não atravessam DLL/`foreign`.
**v1.11 (0.18.1):** conta elemento a elemento em `[N]T` (`a + b`, `2 * a`, `-a`, `a += b`; E0331); swizzle `v.x`, `v.xy`, `v.zyx`, `c.bgra` em `[2..4]T` (uma letra lê e grava; E0332); embutidos `sqrt min max clamp abs` (também por elemento em `[N]T`; E0334); `quat` (`{x, y, z, w: f32}`, `q * r`, `q * v`, `conj(q)`; E0333); lista fixa `var l: [dynamic, 4]i32 = {}` + `append(&l, item = x)` (cheia = R0009, `len`, `for`, cópia por valor; N 1..65536, até 64 tipos; E0335); `forja test --filtro <texto> --json`; vazamento por teste = R0009 e acesso inválido em teste = R0011; `var` nunca mudada = E0707, local nunca lida = E0708 (prefixo `_` isenta), `size_of/align_of/offset_of/static_assert` existem na árvore nova, NÃO na cópia congelada 0.18.0 do engine.
